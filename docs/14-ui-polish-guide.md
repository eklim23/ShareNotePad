# ShareNotepad UI 폴리시 가이드

이 문서는 ShareNotepad의 UI를 다듬을 때 따르는 기준이다.

목표는 화려한 앱이 아니라, Windows 11 메모장처럼 바로 이해되는 공유 메모장이다.

## 1. UI 목표

- 첫인상은 Windows 11 메모장과 최대한 비슷해야 한다.
- 사용자가 "이 버튼은 뭐지?"라고 느끼는 요소를 두지 않는다.
- 실제로 동작하지 않는 버튼은 화면에 노출하지 않는다.
- 공유 기능은 메모장 경험을 해치지 않는 위치에 둔다.
- 기능 설명 문구보다 익숙한 메뉴명과 상태 표시를 우선한다.

## 2. 상단 탭 기준

- 탭은 반드시 탭처럼 구분되어 보여야 한다.
- 활성 탭과 비활성 탭은 배경색, 테두리, 글자 밝기로 구분한다.
- 점, 장식 문자, 의미가 불명확한 표시로 탭 상태를 표현하지 않는다.
- 창이 좁아지면 탭 폭을 줄이고, 제목은 단계적으로 짧게 표시한다.
- 탭 제목이 탭 영역 밖으로 넘어가면 안 된다.
- `+` 버튼은 새 탭 기능만 담당한다.
- 공유 중에는 탭 전환과 새 탭 생성을 막아 문서 동기화 혼선을 피한다.

## 3. 명령바 기준

- 기본 메뉴는 `파일`, `편집`, `보기`, `공유`를 유지한다.
- 자주 쓰는 편집 버튼은 텍스트로 의미가 드러나야 한다.
- 아이콘만 쓸 경우 툴팁 또는 매우 익숙한 기호가 필요하다.
- 아직 구현하지 않은 기능은 버튼을 숨긴다.
- 창이 좁아지면 오른쪽의 보조 버튼부터 숨긴다.
- 메뉴 버튼과 문서 편집 영역이 겹치면 안 된다.

## 4. 편집 영역 기준

- 기본 편집 경험은 메모장처럼 단순해야 한다.
- 한국어 IME 조합 중에는 마크다운 변환이나 동기화가 과하게 개입하지 않는다.
- `# `, `## `, `### `, `- `, `* `, `> `, 세 개의 백틱 + Space는 Notion식 빠른 서식 변환으로 처리한다.
- 변환 뒤 마크다운 마커는 남기지 않는다.
- 줄바꿈 후 제목/코드 스타일이 계속 이어지면 안 된다.
- 마크다운 미리보기는 보조 패널이며, 기본 편집 흐름을 방해하지 않는다.

## 5. 저장과 상태 표시

- 기본 저장 위치는 `%USERPROFILE%\Documents\ShareNotepad`이다.
- 자동 저장 상태는 하단 상태바에 짧게 표시한다.
- 사용자가 파일 위치를 궁금해할 수 있으므로 문서와 UI에서 저장 위치를 명확히 설명한다.
- 연결 상태는 `오프라인`, `연결됨`, `재연결 중`, `끊김`처럼 즉시 이해되는 단어를 사용한다.

## 6. 검증 체크리스트

- Debug 빌드 성공
- Release 빌드 성공
- 단위/스모크 테스트 통과
- 기본 크기에서 탭/명령바/편집 영역 겹침 없음
- 작은 창에서 탭 제목이 영역 밖으로 넘어가지 않음
- 마크다운 단축 변환 후 입력 흐름이 유지됨
- 공유 관련 버튼이 현재 상태와 맞게 활성/비활성 처리됨
