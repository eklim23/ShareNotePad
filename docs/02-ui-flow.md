# UI 흐름 문서

## 원칙

사용자는 네트워크, 포트, 서버, 동기화 알고리즘을 몰라도 된다.

UI에 노출되는 핵심 단어는 다음으로 제한한다.

- 방 만들기
- 방 들어가기
- 같이 쓰기

ShareNotepad는 별도의 런처 화면보다 실제 Windows 11 메모장에 가까운 사용감을 우선한다.
프로그램을 실행하면 즉시 편집 화면이 열리고, 공유 기능은 상단 명령바에 배치한다.

## 화면 목록

| 화면 | 목적 |
| --- | --- |
| 메모장 화면 | 편집과 연결 상태 표시 |
| 방 입장 화면 | 초대 코드와 주소 입력 |
| 오류 표시 | 연결 실패, 코드 오류 등 짧은 안내 |

## 메모장 화면

```text
┌────────────────────────────────────────┐
│ current.txt     제목 없음      +        │
│ 파일  편집  보기     제목 목록 굵게 ... │
├────────────────────────────────────────┤
│                                        │
│  여기에 텍스트 입력                    │
│                                        │
│                                        │
├────────────────────────────────────────┤
│ Idle | 로컬 메모장                      │
└────────────────────────────────────────┘
```

동작:

- 최근 문서가 있으면 자동으로 로드하되, 연결은 시작하지 않는다.
- 상단 명령바의 `공유`에서 방 만들기/방 들어가기/초대 코드 복사를 실행한다.
- `보기 > 마크다운 미리보기`를 켜면 편집창 오른쪽에 가벼운 Markdown 미리보기를 표시한다.
- 편집창에서 `#`, `##`, `###`, `-`, `*`, `>`, 세 개의 백틱을 입력한 뒤 Space를 누르면 현재 줄 스타일을 바로 적용한다.
- 툴바는 아이콘 단독보다 `제목`, `목록`, `굵게`, `기울임`, `링크`, `MD 보기`, `공유`처럼 용도가 보이는 텍스트 버튼을 우선한다.
- 상단 탭은 실제 로컬 탭이다. `+`를 누르면 새 탭을 만들고, 탭을 누르면 문서 내용을 전환한다.
- MVP에서는 공유 중 문서 충돌을 피하기 위해 탭 전환과 새 탭 생성을 제한한다.
- 활성 탭은 밝은 탭 박스, 비활성 탭은 어두운 탭 박스로 구분한다.
- 창 폭이 줄어들면 탭 폭을 자동으로 줄이고, 툴바 버튼은 핵심 메뉴와 공유 버튼을 우선 남긴다.

## 방 생성 흐름

```text
공유 > 방 만들기
↓
상태바: Hosting | 방 코드 482913 | 연결 대기 중 | 포트 7777
↓
공유 > 초대 코드 복사
```

동작:

- 로컬 TCP 서버가 시작된 뒤 표시한다.
- 포트 오픈 실패 시 오류를 표시한다.
- 호스트도 같은 메모장 화면에서 계속 편집한다.

## 방 입장 화면

```text
┌──────────────────────────────┐
│ 방 들어가기                   │
├──────────────────────────────┤
│ 초대 코드: [482913        ]   │
│ 연결 주소: [192.168.0.15 ]   │
│ 포트:      [7777          ]   │
│                              │
│ [연결]                        │
└──────────────────────────────┘
```

MVP에서는 자동 탐색을 지원하더라도 수동 주소 입력을 반드시 유지한다.

구성:

- 상단: 실제 메모장과 유사한 다크 탭/명령바
- 중앙: multiline Edit control
- 선택: Markdown 미리보기 패널
- 하단: 상태바

Markdown 미리보기 MVP 지원 범위:

- `#`, `##`, `###` 제목
- `-`, `*`, `+` 목록
- `- [ ]`, `- [x]` 체크박스
- `> ` 인용
- `` `inline code` `` 기초 표시
- `` ``` `` 코드 블록
- `[텍스트](주소)` 링크 기초 표시

Notion식 입력 변환 MVP 지원 범위:

- `#` + Space: 제목 1
- `##` + Space: 제목 2
- `###` + Space: 제목 3
- `-` 또는 `*` + Space: 목록
- `>` + Space: 인용
- 세 개의 백틱 + Space: 코드 스타일

입력 변환 후에는 Notion처럼 입력한 Markdown 마커를 화면에서 제거한다.
줄바꿈하면 제목/코드 스타일이 다음 줄까지 과하게 이어지지 않도록 기본 스타일로 돌아간다.

상태바 예:

- `연결 대기 중`
- `연결됨 | 지연 8ms | 자동저장 완료`
- `재연결 중...`
- `연결 끊김 | 로컬 저장됨`
- `동기화 중...`

## UI 상태

| 상태 | 설명 | 사용자 입력 |
| --- | --- | --- |
| `Idle` | 시작 화면 | 가능 |
| `Hosting` | 방 생성 후 접속 대기 | 가능 |
| `Connecting` | 상대 서버 접속 중 | 메모장 비활성 |
| `Syncing` | 전체 문서 동기화 중 | 메모장 비활성 |
| `Connected` | 실시간 편집 가능 | 가능 |
| `Reconnecting` | 재연결 시도 중 | 로컬 입력 가능, 전송 대기 |
| `Disconnected` | 연결 끊김 | 로컬 입력 가능 |

## 오류 표시 원칙

오류는 기술 용어를 그대로 노출하지 않는다.

| 내부 오류 | 사용자 문구 |
| --- | --- |
| `invalid_code` | 초대 코드가 맞지 않습니다. |
| `room_full` | 이 방은 이미 사용 중입니다. |
| `connect_timeout` | 상대 노트북에 연결할 수 없습니다. |
| `port_in_use` | 사용할 포트가 이미 사용 중입니다. |
| `firewall_blocked` | Windows 방화벽에서 연결이 막혔을 수 있습니다. |

## 단축키

메모장에 가까운 기본 단축키를 유지한다.

- Ctrl+C
- Ctrl+V
- Ctrl+X
- Ctrl+A
- Ctrl+Z
- Ctrl+T
- Ctrl+S
